# HTTP-сервис чтения новостей Ведомости

Сервис для получения и отображения новостей с сайта Ведомости в формате HTML.

## Установка

1. Установите зависимости:
```bash
npm install
```

## Запуск

```bash
npm start
```

Сервер запустится на `http://localhost:3000`

## Использование

Формат запроса:
```
http://localhost:3000/ЧИСЛО/news/for/CATEGORY
```

Где:
- `ЧИСЛО` - количество новостей (положительное целое число)
- `CATEGORY` - категория новостей (business, economic, finances, politics, auto)

### Примеры запросов:

- `http://localhost:3000/10/news/for/business` - 10 новостей из категории Бизнес
- `http://localhost:3000/5/news/for/politics` - 5 новостей из категории Политика
- `http://localhost:3000/15/news/for/economic` - 15 новостей из категории Экономика


## Структура проекта

- `server.js` - основной файл сервера
- `views/news.ejs` - EJS шаблон для отображения новостей
- `package.json` - зависимости проекта
